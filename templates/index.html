AI Theory Reference
Blackboard Architecture

A shared memory space all agents read/write. Decouples agents — they never call each other directly. Used in NASA mission planning, air traffic control, and network management systems.

BFS — Uninformed Search

Explores nodes level-by-level using a FIFO queue. Guarantees shortest path (fewest hops). Time/Space: O(V+E). Real use: peer-to-peer network search, LinkedIn connections.

DFS — Uninformed Search

Dives deep using a LIFO stack. Memory efficient (stores only current branch). Does not guarantee shortest path. Real use: web crawlers, dependency resolution, network vulnerability scanners.

Greedy — Informed Heuristic Search

Always picks the cheapest edge (lowest ms latency) using a min-heap priority queue. Makes locally optimal choices. Does not guarantee global optimum. Real use: OSPF routing protocol, GPS navigation.
